# 灵镜塔罗 - 塔罗师个人品牌网站

✦ 一个优雅的塔罗师个人品牌展示网站，采用现代设计风格与神秘气质的完美结合。

## 🌟 网站特色

### 设计亮点
- **星空背景**：动态闪烁的星空背景，营造神秘氛围
- **3D卡牌翻转**：Hero区域的交互式卡牌翻转效果
- **平滑动画**：全站滚动渐入、按钮悬停光晕效果
- **响应式设计**：完美支持桌面和移动设备
- **玻璃态导航**：毛玻璃效果的固定导航栏

### 核心功能
- 完整的塔罗师自我介绍
- 4类塔罗咨询服务展示（全面占卜、感情专询、事业指引、年度流年）
- 来访者评价轮播
- 塔罗知识博客板块
- 完整的联系方式和在线预约指引

## 🚀 使用技术

- **HTML5** - 语义化标签
- **CSS3** - Grid布局、动画、渐变
- **JavaScript** - DOM交互、动画控制

## ✨ 主要功能模块

### 1. 导航栏 (Navbar)
- 固定顶部导航
- 响应式汉堡菜单
- 滚动时添加阴影效果
- 链接悬停下划线动画

### 2. Hero区域
- 3D卡牌翻转交互

### 3. 关于我区域
- 个人介绍文本

### 4. 服务项目
- 4张服务卡片
- 价格和时长显示
- 悬停提升效果
- 顶部光线动画

### 5. 评价轮播
- 自动轮播（5秒切换）
- 手动点击控制
- 淡入淡出动画
- 星级展示

### 6. 博客板块
- 3篇示例文章
- 日期、标题、摘要展示
- 卡片悬停效果

### 7. 联系方式
- 微信、邮箱、小红书、在线时间

- 首次咨询优惠提示

### 8. Footer
- 品牌名称
- 品牌座右铭
- 版权信息

## 🎯 JavaScript交互

### 汉堡菜单
- 点击按钮切换菜单显示
- 点击菜单项自动关闭
- 三条线动画变换

### 导航栏效果
- 滚动距离 > 50px 时添加阴影

### 评价轮播
- 自动轮播：每5秒切换一次
- 手动控制：点击圆点按钮
- 切换时刷新计时器

### 滚动渐入动画
- 使用 IntersectionObserver API
- 当元素进入视口时添加 'visible' 类
- 触发淡入 + 向上移动动画

### 动态星空背景
- 根据屏幕宽度生成50-100个星星
- 随机位置、大小、透明度
- 窗口缩放时重新生成

## 📱 响应式设计

在 768px 及以下屏幕上：
- 汉堡菜单展示
- Hero标题缩小到 2.2rem
- 关于我区域单列布局
- 头像居中显示
- 联系方式单列布局
- 所有网格改为单列

## 🔧 如何使用

1. **克隆或下载项目**
   ```bash
   git clone https://github.com/apricot2290/tarot-site.git
   cd tarot-site
   ```

2. **本地预览**
   - 直接用浏览器打开 `index.html`
   - 或使用本地服务器（如 Python）：
   ```bash
   python -m http.server 8000
   ```
   然后访问 `http://localhost:8000`

3. **自定义修改**
   - 编辑 `index.html` 修改内容
   - 编辑 `css/style.css` 修改样式
   - 编辑 `js/main.js` 修改交互逻辑

## 📝 自定义建议

### 替换内容
- 修改 `nav-logo` 为你的品牌名
- 更新所有文本内容
- 替换头像（添加图片到img文件夹）
- 更新服务项目和价格
- 修改联系方式

### 样式定制
- 在 `:root` 中调整 CSS 变量
- 修改主色调（`--accent-gold`）
- 调整字体（`--font-main`, `--font-sans`）
- 改变背景渐变色

### 添加功能
- 接入在线预约系统
- 添加评论功能
- 集成支付系统
- 添加搜索功能
